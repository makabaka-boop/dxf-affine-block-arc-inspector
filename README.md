# DXF 块实例圆弧验图页面

浏览器端 ASCII DXF 导入与 INSERT 实例展开工具。页面直接读取本地文件，不上传图纸；解析、变换、量测和显示全部在浏览器内完成。

## 覆盖范围

仅接受需求规定的平面实体：

- `LINE`
- `LWPOLYLINE`（含闭合标志和逐顶点 `bulge`）
- `BLOCK` / `ENDBLK`
- 非阵列 `INSERT`

并强制：

- `Z = 0`
- 默认挤出方向 `(0, 0, 1)`
- `INSERT` 的 Z 缩放为 1
- 块嵌套最多 4 层
- 单次展开后最多 60 个 LINE / LWPOLYLINE 实体
- 不接受阵列、外部参照、属性、文字、宽线、厚度、3D 多段线等

循环块引用、未知块名、零比例会明确报错；负比例按镜像处理。

## 几何处理

实现位于：

- `src/dxf/parser.js`：ASCII group-code/value 解析和约束检查
- `src/geometry/transform.js`：块基点、缩放、旋转和父变换组合
- `src/geometry/arc.js`：bulge 圆、方向、扫略角、参数曲线极值和椭圆弧参数
- `src/dxf/expand.js`：块递归展开、循环检测、路径保留和实例级比例覆盖

关键规则：

1. 块实体先相对于块基点定义，INSERT 时组合：插入点、旋转、X/Y 缩放、基点平移、父级 INSERT 变换。
2. 每个叶子实体都保留完整插入路径，路径中包含源实例 OID、块名、插入点、比例、旋转和嵌套层级。
3. `LWPOLYLINE` 闭合时，最后一个顶点的 bulge 生成回到第一点的闭合弧段；该弧不会被替换成弦。
4. 非均匀缩放或镜像后，模型仍保存“原始圆参数 + 仿射矩阵”的参数曲线；渲染输出真实 SVG 椭圆弧。
5. 包围盒由端点和变换后参数曲线的 X/Y 内部极值共同构成。缩放视图只修改显示矩阵，不修改这些图纸坐标量测值。
6. 实例比例编辑以“完整插入路径”为 key 写入覆盖表，再从不可变解析结果重新展开，因此不会污染共享块定义或其他实例。

## 本地运行

不安装任何前端依赖，使用普通静态 HTTP 服务即可：

```bash
npm start
# http://localhost:8080
```

或：

```bash
python3 -m http.server 8080
```

## Compose 发布

```bash
docker compose up --build -d
```

发布后访问 `http://localhost:8080`。

```bash
npm test
```

测试覆盖非零基点、两层嵌套、负比例、闭合 bulge 段、非均匀缩放包围盒、跨象限大弧、循环引用、未知块、零缩放、嵌套深度和 Z 平面限制。

## 操作

- 点击左上按钮或拖放 `.dxf` 文件导入。
- 左侧实例树选择具体 INSERT、叶子实体或单段圆弧 / 直线。
- 右侧查看完整插入路径、图纸坐标端点、弧方向、变换行列式和含弧内极值的包围盒。
- 在某个 INSERT 上修改 X/Y 比例，仅影响该完整路径对应实例。
- 鼠标滚轮缩放，拖拽平移；所有量测仍显示图纸坐标。
- 在审图意见中为当前选择记录问题，定位按钮可指回具体插入实例或曲线段。
